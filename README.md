# 📚 Bookstore Sales Analysis using SQL

## Project Overview
This project analyzes a bookstore database using SQL to understand sales performance, customer behavior and inventory. The goal is to turn raw data into clear business insights.

## Business Questions Answered
- Which books and genres sell the most?
- Which customers spend the most?
- How does revenue change over time?
- Which books are low in stock?
- Which authors bring in the highest revenue?

## Tools Used
- SQL (PostgreSQL)
- GitHub

## SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY
- JOINS (INNER, LEFT)
- Aggregate functions (SUM, COUNT, AVG)
- Subqueries
- Window functions
